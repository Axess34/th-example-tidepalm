# Tide & Palm Beach Bar (Thai Local example site)

A fictional example website (beach bar, Koh Lanta) made by Thai Local (https://thailocal.online/) to show what a local business website can look like. The business, prices, reviews and contact details are placeholders. The site is noindex and robots.txt blocks crawlers.

Live: https://tidepalm.thailocal.online/
